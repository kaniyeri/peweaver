# PEWeaver source

Start with the [project README](../../../README.md) for the result tables and quick start.

- `orchestration/chia_merge.py`: merge controller.
- `orchestration/chia_power_save.py`: area and power search controller.
- `orchestration/peweaver_chia_graph.py`: FFT experiment.
- `physical/run-physical.sh`: FFT implementation and measurement flow.

Run local checks from the `chia/` directory with `./examples/peweaver/run-local.sh`.
